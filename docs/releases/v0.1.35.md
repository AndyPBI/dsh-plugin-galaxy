# dsh-plugin-galaxy 0.1.35

修复桌面版报告的「**4508 个插件 / 没有甄选 / 没有分类筛选**」。

## 原因：两条数据原因叠加（不是缓存，也不是没装上）

1. 该 profile 没配 `catalogUrl` → 回落到**内置公共目录** `awesome-dsh-plugin.com/plugins.json`
   （实测正好 **4508 条**、无 `ranking` 块）→「推荐」按设计退化为「未安装」，甄选自然没有；
2. 那份目录的分类词表是**映射**形状（`{ "agi": { "zh": "…", "en": "…" } }`），旧加载器只认数组
   → 词表被丢弃 → 分类选择器与甄选 chip **无处渲染**（面板的这两处完全由数据驱动）。

## 本次改动

- **设置卡片新增「目录来源」**：直接填「目录地址 + 官网基址」即可（不必再设环境变量或改 JSON），
  并显示"当前生效 + 来源（环境变量 / 本 profile / 内置）"——环境变量优先，所以"保存了却不变"会被解释清楚。
  保存后面板通过事件**立即重新拉取**，不需要手动点刷新。
- **加载器兼容两种词表形状**（数组 / 映射），标签按 `label → zh → name` 与 `labelEn → en` 读取；
  消费侧门禁同步归一，对两类目录都能正确判定。
- 服务端只新增一个 `POST /catalog-source`（读侧并入 `/status`，保持"每个路径只注册一次"的约定）；
  校验 http(s)、写入取互斥锁、并使基于旧 origin 的缓存失效。
