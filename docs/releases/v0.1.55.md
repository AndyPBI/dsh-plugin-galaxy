# dsh-plugin-galaxy 0.1.55

插件市场的**状态筛选改为滑轨**，卡片版式重做，任务记录面板重排，并新增卡片「简介」与服务端 `/intro` 缓存。

## 市场：状态筛选从「一排胶囊」改为「一条滑轨」

原先六个互斥状态是六枚各自重绘的 chip，点完分不清"选中"和"鼠标还停在这"。现在：

| 项 | 做法 |
|---|---|
| 选中态 | **一枚会移动的 thumb**（`translateX` → 实测 `offsetLeft/offsetWidth`），0.3s 缓动 |
| 段宽 | **按标签自适应**（统一内边距），不再等分——等分会把「全部」浮在半个空格子里，而「已安装 8」被挤 |
| 垂直对齐 | 段高 28 + 轨道内边距 2 = **32px，与两个下拉严格等高**；内容居中，不再基线贴顶 |
| 计数 | 「已安装」「可更新」带真实计数（按整个已安装清单统计，不随搜索收窄），`aria-label` 只报状态名 |
| 分页 | 窄容器里滑轨不再横向滚动（滚动条视为布局坏了）；`< 520px` 才隐藏计数 |

## 工具条：三行压到两行（宽容器）

「分类筛选」「排序」上移到滑轨同一行，并去掉两个下拉的行内文字标签（`全部分类`、`评分 · 降序` 本身自解释，`aria-label` 保留）。

修掉三个真实布局缺陷：

1. `.toolbarLine` 的 `flex-wrap: nowrap` 覆盖了 `wrap`，导致整行永不折行，轨道被压到 422px 并出现横向滚动条
2. 换行按**基准宽度**决策（早于收缩），分类框 320px 基准把两个下拉挤到第三行；窄容器里压到 200px（省略号 + `title` 兜底）
3. 两个下拉各自换行（分类留下、排序单独掉一行），现成组整体换行

实测（宿主设置列 564px）：轨道 312px、六项一行、无溢出、卡片两列。

## 卡片与面板

- 卡片改为**四行版式**，网格固定两列并适配窄卡片
- 任务记录面板重做（`OperationsPanel`），底栏单行，卸载/安装按钮统一样式与点击区域
- 卡片新增**「简介」**：正文来自官网，服务端 `/intro` 缓存；弹窗关闭图标 18×18、按钮 28×28
- 品牌配色固定
