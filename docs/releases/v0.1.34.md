# dsh-plugin-galaxy 0.1.34

装在 **DeepSeek Harness 设置对话框**里的插件市场：逛、搜、按分类浏览、一键安装，
更新/启停/卸载/备份恢复/诊断都在同一个面板里完成。不占侧栏座位，不往会话里塞命令。

## 安装

本包**不在 npm 上**（`dsh plugin add dsh-plugin-galaxy` 不会成功）。两种方式：

```bash
# A. 下载本 Release 的附件后安装
dsh plugin --profile web add ./dsh-plugin-galaxy-0.1.34.tgz

# B. 直接从本 Release 的资产地址安装
dsh plugin --profile web add \
  https://github.com/AndyPBI/dsh-plugin-galaxy/releases/download/v0.1.34/dsh-plugin-galaxy-0.1.34.tgz
```

装完需**完整重启宿主**（插件在宿主启动时装载），然后在 **设置 → 插件星系** 打开。

要求：DSH `>=0.1.5-alpha.1`（0.2.x 需 Node `^22.19.0 || >=24.0.0`）；安装使用宿主的 pnpm，
打包版桌面应用使用其自带运行时。

## 本次亮点

- **分类筛选**：工具栏「分类筛选」由官网目录的分类词表生成；词表首个分类（甄选 / Featured）
  直接作为 chip 显示在「全部」之后，完整词表在下拉里，可与状态筛选、搜索叠加。官网新增或改名分类，面板自动跟随。
- **工具栏布局**：改为三行结构（搜索 / chips / 控件），「分类筛选」与「排序」严格同行，且在任何对话框宽度下
  不重叠、不出框（容器查询 + 宽度上限，实测 1044 / 420 / 380px）。
- **两代宿主 + 桌面版**：同时支持 `0.1.5-rc.2` 与 `0.2.1-alpha.1`，含 Windows/macOS 桌面版
  （打包应用自带 pnpm、`profileContext` 解析 profile、外壳拥有生命周期时禁用自重启）。
- **推荐视图**：卡片带官网排名 `#1`、`#2`… 与分档、评分构成与"为什么推荐"，跳过已安装自动补位。
- **权限与安全**：无遥测、凭据不落盘、无 postinstall；变更操作前先快照 profile，失败自动回滚。
