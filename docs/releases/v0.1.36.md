# dsh-plugin-galaxy 0.1.36

**内置默认目录改成官网** —— 桌面版新装即可与官网一致（305 条 + 甄选 + 分类筛选），不再需要手工配置。

## 改动

- `DEFAULT_CATALOG_URL` → `https://www.yhaigc.cn/assets/plugins/catalog.json`
  （区域表里的目录候选地址同步更新）。优先级不变：`DSHG_REGISTRY_URL` → profile 的 `catalogUrl` → 内置默认。
- 「设置 → 目录来源」里"来源"的措辞改为**内置默认目录（官网）**；保存/恢复默认的行为不变。
- **更新说明（`updates.json`）仍取聚合源**：官网目前不提供该文件（404），指过去只会让「更新日志」变成空内容
  （不报错）。两个来源相互独立，`DSHG_UPDATES_ORIGIN` 可单独覆盖；官网若日后自建，按
  `{ updates: { "<行的 url>": { release|releases, commits } } }` 形状发布即可切换。

## 影响面

- **新 profile / 未配置过目录**：装上就是官网目录（本次目标）。
- **已显式配置过 `catalogUrl` 的 profile**（含环境变量覆盖）：行为不变，仍按配置走。
- 发现类数据（分类/甄选/推荐榜/★/下载量）随官网目录快照；**更新检查**依旧走 npm registry 与 GitHub 提交，
  与目录更新节奏无关。

## 验证

- 测试 **211/211**（新增：内置默认目录必须是官网；环境变量与 profile 覆盖优先级；空白值回落）
- `npm run release` 全门禁通过（产物 / 客户端冒烟 / 合规 / 宿主契约 0.2.1 / 宿主设置 / 真 Chrome 布局）
