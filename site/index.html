Plugin Galaxy

DeepSeek Harness 的可视化插件星系：逛一逛，点一下，装好。
A visual plugin galaxy inside DeepSeek Harness — browse, search, and one-click install community plugins.

安装 / Install

dsh plugin add dsh-plugin-galaxy

安装后在宿主设置对话框左侧打开 Plugin Galaxy 即可。

它做什么 / What it does

  • Discover — 浏览 curated catalog，搜索、筛选、兼容性预判，一键安装
  • Installed — 启停 / 更新 / 卸载 / 备注 / 分组 / 收藏 / 查看更新记录
  • Favorites — 收藏待装插件
  • Themes — 互斥激活主题型插件
  • Operations — 变更操作生命周期、取消与回滚
  • Diagnostics — 包清单诊断与脱敏日志导出
  • Settings — 备份 / 恢复 / WebDAV / Gist / 区域 / 代理 / 通道 / 重启 / 自我卸载

设计契约 / Design contract

服务端与客户端各自有一份自持契约：docs/implementation-contract.md（路由、对象、规则、状态文件） 与 docs/client-contract.md（槽位、组件、文案、布局）；模块与能力的对应关系见 docs/spec-implementation-mapping.md。
